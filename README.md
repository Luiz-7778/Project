# 🎨 Fantasy Female Character Creation Realm

## Objective

This project is dedicated to creating original female fantasy characters with a high level of detail. Every generated character should feel unique, immersive, and suitable for games, RPGs, novels, concept art, or AI image generation.

---

# Character Guidelines

Every character must include:

- Name
- Age
- Race
- Height
- Personality
- Background Story
- Occupation
- Fighting Style

---

# Appearance

Always describe:

- Face shape
- Eye color
- Eye details
- Hair color
- Hair style
- Hair length
- Skin tone
- Body type
- Scars (if any)
- Tattoos (optional)
- Accessories

Descriptions should be vivid and highly detailed.

---

# Clothing

Every outfit must include:

- Upper clothing
- Lower clothing
- Gloves
- Belt
- Boots
- Cape (optional)
- Jewelry
- Decorative details
- Fabric type
- Primary colors
- Secondary colors

Clothing should match the character's personality and profession.

---

# Armor

Armor should include:

- Helmet (optional)
- Shoulder Armor
- Chest Armor
- Arm Guards
- Gloves
- Waist Protection
- Leg Armor
- Boots
- Materials
- Magical Runes
- Decorative Symbols

Armor should appear functional while remaining elegant and visually striking.

---

# Weapons

Describe every weapon in detail:

- Weapon Type
- Name
- Material
- Blade Shape
- Guard Design
- Handle Material
- Gemstones
- Magic Effects
- Special Abilities
- Combat Style

Examples:

- Long Sword
- Great Sword
- Katana
- Rapier
- Twin Blades
- Spear
- Magic Staff

---

- Originality
